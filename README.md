# Seshat's Calendar

Welcome to **Seshat's Calendar** – a unique calendar system featuring 13 months of 28 days each, starting April 1st 2030, with intercalaris days.

## Links

- **GitHub Repository**: [MLSpyShop/Seshat-s-Calendar](https://github.com/MLSpyShop/Seshat-s-Calendar)
- **GitHub Pages**: [Seshat's Calendar GitHub Pages](https://mlspyshop.github.io/Seshat-s-Calendar/)

## Overview

This project implements an alternative calendar system that divides the year into 13 equal months with 28 days each, incorporating intercalaris days to maintain astronomical accuracy.

### Key Features

- **13 Equal Months** - Each month contains exactly 28 days
- **Starts April 1st 2030** - Calendar epoch begins on this date
- **Intercalaris Days** - Special days included to align with Earth's orbital period
- **TypeScript Implementation** - Built with TypeScript for type safety and modern development
